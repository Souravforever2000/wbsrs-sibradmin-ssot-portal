Algorithm Explanation Breakdown

Jaro-Winkler: Best for human names and prefix matches, including transpositions and character swaps.

Levenshtein Distance: Counts minimum single-character edits such as insertions, deletions, and substitutions.

Token Sort Ratio: Normalizes and sorts words before comparison, helpful when name word order differs.

Soundex Phonetics: Encodes names according to pronunciation so similarly pronounced names can be identified.
